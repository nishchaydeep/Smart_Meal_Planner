# Screenshots Directory

## Required Screenshots

Please add the following screenshots to this directory:

1. **homepage.png** - Main page showing profile setup interface
2. **ingredient-search.png** - Ingredient search feature in action
3. **recipe-suggestions.png** - Personalized recipe suggestions display
4. **meal-history.png** - Meal history tracking interface

## How to Take Screenshots

1. Start the web server:
   ```bash
   npm run web
   ```

2. Open http://localhost:3000 in your browser

3. Take screenshots of each feature:
   - Use full browser window
   - Recommended size: 1920x1080 or similar
   - Save as PNG format for best quality

4. Name the files exactly as listed above

5. Place them in this `screenshots/` directory

## Tips for Good Screenshots

- Use light/default theme for consistency
- Include realistic sample data
- Capture full feature UI (don't crop important elements)
- Use consistent browser window size
- Clear any personal information before taking screenshots
